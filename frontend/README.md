# Reboot website

React + TypeScript site built with [Vite](https://vite.dev/). Requires Node.js 24 and Yarn 1.

## Available Scripts

In the project directory, you can run:

### `yarn dev`

Runs the app in development mode at [http://localhost:5173](http://localhost:5173). The page reloads when you edit files.

### `yarn test`

Runs the tests once with [Vitest](https://vitest.dev/).

### `yarn build`

Type-checks the code and builds the app for production into the `dist` folder.

### `yarn preview`

Serves the production build locally.
